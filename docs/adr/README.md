**Cuándo escribir un ADR:** si una persona que llega hoy al proyecto vería el código y preguntaría *"¿por qué lo hicieron así?"*.

**Cómo se generan:** se transcribe a MADR una decisión que ya se tomó, a partir del documento técnico, el roadmap o la conversación con el agente. La IA llena la plantilla y el autor valida el razonamiento (M5 §5.2).
